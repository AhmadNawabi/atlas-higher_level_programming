## Project Overview

This repository is structured as a series of folders, each representing a specific area of programming learning:

| `SQL_more_queries` | Advanced SQL queries including joins and aggregations |

| `javascript-web_jquery` | Front-end exercises using JavaScript and jQuery |
| `javascript-web_scraping` | Scripts for web scraping and DOM manipulation |
| `javascript_objects_scopes_closures` | JavaScript object-oriented concepts, scopes, and closures |
| `python-almost_a_circle` | Python object manipulation and geometric exercises |
| `python-classes` | Class creation, inheritance, and OOP exercises in Python |
| `python-data_structures` | Implementation of Python data structures |
| `python-everything_is_object` | Understanding Python object model |
| `python-exceptions` | Exception handling exercises |
| `python-hello_world` | Basic Python syntax and introductory exercises |
| `python-if_else_loops_functions` | Python control structures and function practice |
| `python-import_modules` | Using and creating Python modules |
| `python-inheritance` | Inheritance and OOP exercises |
| `python-input_output` | File handling and input/output operations |
| `python-more_classes` | Advanced class exercises and inheritance |
| `python-more_data_structures` | More complex data structure exercises |
| `python-object_relational_mapping` | Object relational mapping and database integration |

## Usage

To get started with any of the exercises or scripts:

1. **Clone the repository:**
```bash
git clone https://github.com/AhmadNawabi/Atlas-Higher-Level-Programming.git
cd Atlas-Higher-Level-Programming
```

2. **Navigate to a folder of interest**:
```bash
cd python-classes  # Example
```

3. **Run scripts**:
- For Python files:
```bash
python3 script_name.py
```
- For JavaScript files:
```bash
node script_name.js
```
- For SQL files: Use any SQL client to execute the `.sql` scripts.

4. **Explore the exercises**: Each folder contains files with clearly defined tasks and instructions.
